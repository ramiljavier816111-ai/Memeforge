How do “Provider” and “Mobile app link” work?

Provider is the spot in the browser where the wallet extension puts itself, for example phantom.solana or okxwallet.solana. The page looks it up to show “Detected” and connect. If a wallet is installed but not detected, its provider is probably different, so edit it here. Leave it empty to just show an “Install” link.

Detection flag is an extra check such as isPhantom, so another wallet using the same spot is not mistaken for it. Leave it empty if unsure.

Mobile app link opens your page inside the wallet app on phones. Put {url} where the page address goes (and {ref} for your site address). Leave empty if the wallet has no such link.
